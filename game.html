Games and Gaming Technology

Different kinds of games use different tools, devices, and software.

Console Games

Console games are played using systems such as PlayStation, Xbox.

PC Games

PC games use a computer and can benefit from a suitable processor, graphics card, and memory.

Mobile Games

Mobile games let people play on phones and tablets, often using touchscreen controls.

Technology Used in Games

Game engines, graphics processors, internet connections, controllers, and sound systems all help create the gaming experience.
